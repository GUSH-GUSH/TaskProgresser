# Бизнес-сервисы (Services)

**Что сюда класть:**
Классы, реализующие основную прикладную логику приложения на стороне клиента. Они координируют процессы, связывают данные из репозиториев с потребностями форм и управляют состоянием (например, сервис авторизации, который хранит токен).

**Правила:**
- Сервис ничего не знает о WinForms (в нем нет using System.Windows.Forms).
- Сервис работает с бизнес-моделями из слоя `TaskProgresser.Core`.
- Желательно, чтобы каждый сервис имел свой интерфейс (например, `ITokenService`) для удобного тестирования и внедрения зависимостей.
