# Утилиты и Помощники (Helpers / Utils)

**Что сюда класть:**
Статические классы и методы расширения (`Extensions`), которые выполняют рутинные, изолированные задачи без сохранения состояния.

**Правила:**
- Класс должен быть `static`.
- Никакого состояния (полей, меняющих значение).
- Принцип "Вход -> Выход". Например: форматирование дат, математические округления, получение версии сборки.
