# Источники данных (Repositories)

**Что сюда класть:**
Классы, которые отвечают за получение, сохранение и удаление данных. В данном слое приложения это клиенты для обращения к API (`ApiClients`) или классы для чтения/записи локальных файлов кэша.

**Правила:**
- Класс прячет внутри себя логику запросов (HTTP, SQL, файловая система).
- Остальная часть программы (формы, сервисы) не должна знать, ОТКУДА берутся данные, она просто просит у репозитория нужную модель (Task, User).
