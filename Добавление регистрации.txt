Фаза 1: Настройка API (Серверная часть)
1. Установка пакетов +

В проект TaskProgresser.Api через NuGet установи два пакета:

BCrypt.Net-Next

Microsoft.AspNetCore.Authentication.JwtBearer

2. Транспортные модели (DTO) +

В проекте TaskProgresser.Core создай папку DTOs.

Добавь два класса: RegisterRequest (логин и пароль) и AuthResponse (токен и логин).

3. Секретный ключ для токенов +

Так как ты уже умеешь работать с User Secrets, добавь туда (или в appsettings.json) секретную фразу:
"JwtSettings:Secret": "твой_очень_длинный_и_сложный_ключ_минимум_32_символа"

4. Создание контроллера авторизации +

В папке Controllers проекта API создай AuthController.cs.

Вставь туда методы Register (хэширует пароль через BCrypt и сохраняет юзера) и Login (проверяет пароль и генерирует JWT-строку).

5. Настройка конвейера в Program.cs +

Добавь регистрацию сервисов JWT (builder.Services.AddAuthentication...) до строки builder.Build().

Добавь middleware app.UseAuthentication(); строго перед app.UseAuthorization();.

6. Защита задач +

В TasksController.cs повесь атрибут [Authorize] над всем классом.

В методе добавления задачи (POST) замени ручной ввод UserId на извлечение его прямо из токена: User.FindFirst(ClaimTypes.NameIdentifier)?.Value.

Фаза 2: Настройка WinForms (Клиентская часть)
7. Обновление HTTP-клиента

В классе TaskApiClient добавь метод LoginAsync.

Внутри этого метода после успешного получения ответа от сервера пропиши сохранение токена в заголовки: _client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", token);. Теперь все запросы будут идти с "пропуском".

8. Интерфейс

Добавь на форму поля для ввода логина/пароля и кнопку "Войти".

По клику вызывай LoginAsync, и если результат успешный — загружай список задач.

Если какой-то из этих шагов мы уже проговорили достаточно подробно и код у тебя есть, можешь смело его внедрять.

С какого шага начнем копировать и адаптировать код прямо сейчас — с добавления моделей DTO (Шаг 2) или сразу перейдем к настройке ключа (Шаг 3)?


Шаг 1. Окно входа и регистрации (UI)
Создать новую стартовую форму (например, AuthForm), которая будет открываться первой при запуске приложения.

Добавить текстовые поля для логина и пароля, а также кнопки «Войти» и «Зарегистрироваться».

Шаг 2. Интеграция API-клиента (TaskApiClient)
Дописать в твой класс клиента методы для отправки POST-запросов на эндпоинты /api/auth/login и /api/auth/register.

Настроить обработку ответов: если сервер вернул ошибку (например, неверный пароль), выводить MessageBox для пользователя.

Шаг 3. Управление сеансом и сохранение токена
При успешном логине получить токен от сервера.

Применить ту самую идею с Properties.Settings — сохранить токен на жесткий диск, чтобы реализовать автоматический вход без ввода пароля при следующих запусках.

Поместить токен в DefaultRequestHeaders твоего HttpClient, чтобы он автоматически прикреплялся ко всем запросам задач.

Шаг 4. Маршрутизация (Переход к задачам)
После успешной авторизации скрыть AuthForm и открыть твою главную форму с задачами.

Переписать загрузку задач на главной форме: вместо чтения из локального JSON-файла вызывать метод GetAllTasksAsync() из API и передавать данные в DataGridView.
